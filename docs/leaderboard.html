HTSBench — Leaderboard

Resultados agregados (média entre séries) de cada combinação dataset × estratégia de reconciliação × método.

Clique em um cabeçalho de coluna para ordenar. O destaque marca o melhor valor (menor) de cada métrica numérica, por dataset+reconciliação.

Nenhuma linha corresponde aos filtros selecionados.

Gerado a partir de scripts/export_leaderboard_json.py, lendo os registros salvos por scripts/run_experiments.py — veja o README para como reproduzir.
